## 📱 Component Quick Reference

**Form Components:**
- `<x-openBoost-select>` - Dropdown input
- `<x-openBoost-datepicker>` - Date picker
- `<x-openBoost-radioGroup>` - Radio buttons
- `<x-openBoost-toggle>` - Toggle switch

**Data Display:**
- `<x-openBoost-datatable>` - Data table
- `<x-openBoost-list>` - Paginated list

**Layout:**
- `<x-openBoost-accordion>` - Collapsible sections
- `<x-openBoost-carousel>` - Image slider
- `<x-openBoost-tabs>` - Tabbed content

**Feedback:**
- `<x-openBoost-notification>` - Alerts
- `<x-openBoost-tooltip>` - Help text

**Modals:**
- `<x-openBoost-modal>` - Dialog box
- `<x-openBoost-dropdown>` - Menu

**Visualization:**
- `<x-openBoost-chart>` - Charts
- `<x-openBoost-editor>` - Rich text editor
